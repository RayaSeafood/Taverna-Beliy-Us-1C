# Информационная система учёта для настольного антикафе «Таверна "Белый Ус"»

Конфигурация разработана на платформе **1С:Предприятие 8.3** в рамках производственной/учебной практики.

##Назначение системы
Автоматизация работы антикафе с настольными играми: бронирование игровых столов, почасовой расчёт стоимости с учётом акционных тарифов, складской учёт угощений и контроль выдачи/возврата настольных игр.

##Структура проекта (Модули 1–4)
* **Подсистемы:** «Зал таверны», «Игротека», «Склад и угощения», «Администрирование».
* **Справочники:** `Номенклатура` (с хранением фотографий и заглушкой), `Игротека`, `ИгровыеСтолы`, `Тарифы`, `Клиенты`, `Сотрудники`, `Производитель`, `Поставщик`.
* **Документы:** `Заказ` (Бронирование стола), `ПриходТовара`, `ВозвратИгр`.
* **Регистры накопления:** `ОстаткиТоваров`, `ДействующиеИгры`.
* **Обработки и отчёты:** `ЗагрузкаНоменклатуры` (импорт справочника товаров из файлов Excel `.xlsx`), печатная форма квитанции брони с выгрузкой в Excel.

##Роли и разграничение прав
Реализована стартовая форма авторизации с проверкой логина/пароля и гостевым входом:
* **Администратор** (тестовый вход: `admin` / `admin`) — полный доступ ко всем разделам, загрузка данных из Excel, управление сотрудниками.
* **Менеджер** — оформление и проведение бронирований, выдача и возврат игр, складской учёт.
* **Клиент / Гость** — просмотр витрины товаров, игротеки, тарифов и столов в режиме «Только чтение».
